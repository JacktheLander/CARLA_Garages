# SanJose UE4 Export

This folder contains the Unreal 4.26-compatible SanJose copy built from the RoadRunner FBX import.

- Open `SanJoseUE4_426_Copy.uproject` with Unreal Engine 4.26.2.
- The level is `/Game/SanJose/SanJoseLevel`.
- UE4 texture assets are under `Content/SanJose/Textures`.
- CARLA/RoadRunner annotation files are under `Annotations`.

The transient Unreal folders `Saved`, `Intermediate`, and derived data caches are intentionally not included.
